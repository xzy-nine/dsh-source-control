# dsh-source-control

DSH 插件：在 DSH Web GUI 内置右侧 Sidebar 中以「源代码管理」页显示**当前会话工作区**的仓库、提交图、变更列表与
提交框。界面按 VS Code 的「源代码管理 + 图形」视图排布，控件取自 DSH 内置组件，因此外观与 Harness 本身一致。
仓库自动绑定当前会话工作区，无需手动选择。

## 功能

### 存储库

列出当前会话工作区内的仓库，并展开其工作树与子模块。按种类用不同图标区分，同一行显示所在分支与相对上游的
领先 / 落后数量。右键菜单提供刷新、抓取、推送与复制路径；对工作树额外提供「移除工作树」。

### 更改

工作区变更列表，按「暂存的更改 / 更改」两个分组。

- 文件行显示文件类型图标、文件名与最右列的状态字符（与文件夹数量同列）。点击文件行即打开该文件；
  未跟踪的新文件按普通文件打开。
- 悬停出现丢弃与暂存（或取消暂存）按钮；右键菜单提供同样的动作、打开与复制路径。
- 文件树从**最早分叉的公共目录**开始显示：目录逐级只有单个子目录时合并为一行，不再从仓库根逐级展开。
- 提交框固定在顶部，只有变更列表滚动。分组头右键可全部暂存 / 取消暂存 / 丢弃。

### 提交框

- 提交信息支持 Enter 提交、Shift+Enter 换行、Esc 清空草稿。
- 「修补上一次提交」勾选后提交为 `--amend`。
- 提交按钮显示已暂存的文件数量。
- 可由 AI 生成提交信息（见下）。

### 图形

提交泳道图，标题栏可点击收起。标题上方的分界线是拖拽手柄，向上拖让图形变高（120–720px，按会话保存）。

- 每行为「泳道 + 提交信息（作者紧随其后，空间不足时省略号截断）+ 右对齐的引用标记」。
- 引用标记：当前分支与本地分支是「图标 + 名称」药丸，远端、标签、贮藏是圆形图标，名称见悬停提示与右键菜单。
  远程 HEAD 不作为标记列出；被其它工作树检出的分支也不列出。
- 节点形状区分种类：当前分支为双同心圆、合并提交为环加内点、其余为实心点；线段停在节点外沿，不穿过节点。
- 未提交行以虚线表示且不画节点，也不触发浮窗与右键菜单。
- 分页加载时，父提交未加载仍占住泳道并把线画到行底，因此已加载部分的泳道与颜色不会因加载更多而改变。
- 悬停某行浮出卡片：作者、时间、完整提交信息、改动文件与增减行数、引用标记、短哈希与复制按钮。
- 点击某提交在该行下方就地展开改动文件区，逐文件显示 +/− 与状态；点击文件行打开差异，再次点击同一行收起。

#### 提交右键菜单

在 GitHub 上打开（仅有 GitHub 远端时出现）、签出到（二级菜单列出该提交上的分支，仅在分支头位置出现）、
签出（已分离）、创建分支、删除分支、创建标签、删除标签、从此提交拣选、从此提交还原、重置当前分支到此处、
合并到当前分支、变基当前分支到此处、复制哈希、复制提交信息、创建归档。

- **删除分支**的二级菜单列出**包含该提交**的本地与远程分支——分支只由尖端提交标识，中间提交若只看尖端
  会无法删除所属分支。
- **删除标签**在没有标签时不显示。
- **删除当前分支**照常列出，点击后说明原因（而不是置灰）。
- 有二级菜单的项右侧带箭头标识。

### 差异页

在侧边栏中打开文件的差异视图，含行号列、hunk 头与代码高亮。

- **默认左右并排**，可切换为统一视图。
- **默认自动换行**，可切换为不换行。
- 只显示改动附近的行（按 git hunk），而不是整文件。

### GitHub 集成

通过 `gh` CLI 完成，无需在插件内保存令牌（沿用 `gh` 自己的登录凭据）。

| 能力 | 入口 | 说明 |
|---|---|---|
| 创建 Pull Request | 提交右键菜单「创建 Pull Request…」（当前分支为分支尖端、且分支已推送到 GitHub 远程时出现） | 选择目标分支、填写标题与正文，可创建为草稿 |
| 发布到 GitHub | 无远程时的「发布」 | 新建仓库并推送：可选公开 / 私有，可选个人账号或其组织 |

**权限不足时降级而非失败**：未安装 `gh`、未登录、token 缺少所需 scope 时，GitHub 入口隐藏或提示所需 scope 与补授权命令，发布仍可改用手工输入远程地址完成。

### 破坏性操作的确认

以下操作会先弹确认框，确认按钮为红色：丢弃改动、删除本地 / 远程分支、删除标签、丢弃贮藏、重置当前分支、
移除工作树、删除远程仓库配置。合并与变基也走确认框。

**放弃暂存不算破坏性操作**，不加确认。丢弃未跟踪文件时按「删除」措辞——它们是被真正删除而非还原。

### 仓库配置

设置面板提供：

| 分区 | 内容 |
|---|---|
| General | 提交排序（拓扑 / 时间 / 作者时间）、日期格式、提交框与图形区的显示开关 |
| User Details | 用户身份（姓名与邮箱），可写入全局或当前仓库 |
| Remote Configuration | 远程仓库的增删改 |
| Issue Linking | Issue 链接规则 |
| Pull Request Creation | PR 创建相关配置 |
| 仓库配置 | 仓库级配置导出 |
| AI 提交信息 | 专用的供应商与模型，以及追加到系统提示词末尾的自定义规则 |

### AI 提交信息

选择供应商与模型（未配置时回退到当前会话模型），可填写自定义规则；生成时把工作区差异交给所选模型，
流式返回并填入提交框。

勾选「修补上一次提交」后，差异改为「上一次提交的改动 + 本次改动」，提示词同时说明这是修补提交。

## 打开入口

不依赖任何第三方侧栏插件，两个入口打开同一个页：

| 入口 | 行为 |
|---|---|
| 引导页入口胶囊 | 右侧栏 tab 条「+」打开引导页后，点「源代码管理」胶囊 |
| 会话 header 图标按钮 | 直接打开该页；已打开时聚焦 |

切到别的侧栏页或工作区再回来时，页面保持原状（不会重新加载，展开状态也不丢失）。

## 安装

```sh
dsh plugin --profile web add dsh-source-control
# 重启 dsh web，页面右侧栏「+」→ 引导页出现「源代码管理」，会话 header 亦有图标按钮
```

## 与原版的差异

界面、提交图与宿主侧数据层均为本项目自研：

| 项 | 说明 |
|---|---|
| 界面 | 不再内嵌 VS Code webview，改为 DSH 组件构成的侧栏页 |
| 提交图 | 自研的泳道布局与 SVG 渲染 |
| 宿主数据层 | `src/source-control/` 自研实现：直接调用 git，并在本地解析其机器可读输出 |
| VS Code 专属命令 | 打开终端、查看 SCM 等在 DSH 版本中不可用或弱化展示；创建 PR 改由 `gh` CLI 实现 |
| 仓库来源 | 自动绑定当前会话工作区（无工作区时页内显示提示） |
| 新增能力 | 工作区变更面板、提交图、AI 提交信息、差异页、工作树管理、GitHub 集成 |
