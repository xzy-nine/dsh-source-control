# dsh-source-control

DSH 插件：在 DSH Web GUI 内置右侧 Sidebar 中以「源代码管理」页显示**当前会话工作区**的仓库、提交图、变更列表与
提交框。界面控件取自 DSH 内置组件，因此外观与 Harness 本身一致。
仓库自动绑定当前会话工作区，无需手动选择。

[English](README.en.md)

## 功能

- **提交图**：泳道图显示提交与引用标记，分页自动加载，悬停出卡片，点击就地展开改动文件，右键完成检出、
  分支与标签操作。
- **变更与提交**：工作区变更分组列出并可暂存 / 丢弃，提交框支持 Enter 提交与修补上一次提交，提交信息可由
  AI 生成。
- **差异页**：并排 / 统一视图、自动换行、按 hunk 显示。
- **GitHub 集成**：通过 `gh` CLI 新建仓库并推送，以及创建 Pull Request；未安装 / 未登录 / 缺权限时降级。
- **远程协议**：远程地址可在 HTTPS 与 SSH 之间双向切换，切换前检测本地 SSH 状态。
- **安全与反馈**：破坏性操作先确认，操作失败以提示条说明原因。

每一项功能的完整说明见 [doc/功能说明.md](doc/功能说明.md)。

## 打开入口

两个入口都来自本插件，打开同一个页，不依赖第三方侧栏插件：

| 入口 | 行为 |
|---|---|
| 引导页入口胶囊 | 右侧栏 tab 条「+」打开引导页后，点「源代码管理」胶囊 |
| 会话 header 图标按钮 | 直接打开该页；已打开时聚焦 |

切到别的侧栏页或工作区再回来时，页面保持原状（不会重新加载，展开状态也不丢失）。

## 与 dsh-better-sidebar 的配合

装了 [dsh-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar) 时优先用它的能力，未安装或
对应类型被关闭时自动回退，两种情形都无需配置

可选依赖，本插件单独安装即可使用。

## 安装

```sh
dsh plugin --profile web add dsh-source-control
# 重启 dsh web，页面右侧栏「+」→ 引导页出现「源代码管理」，会话 header 亦有图标按钮
```
