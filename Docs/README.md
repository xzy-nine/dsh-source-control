# 文档索引

本文是 `Docs/` 的入口：说明目录分层与每篇文档的范围。文档层级、写作规则与预算见[文档标准](AGENTS.md)。

## 分层

`Docs/` 按读者与主题分两层。`功能/` 描述用户可见的行为与操作，`实现/` 描述代码结构、构建、测试与运行时机制。每篇文档只详述自身主题，直接子项只写用途与高层行为，更低层细节链接到拥有它的后代。
