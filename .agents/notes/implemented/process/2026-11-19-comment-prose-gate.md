# Agent Note: 注释散文门禁

Status: implemented

## Problem

散文标准要求注释只写说明性表述、不写解释性描述，但规则只存在于技能与文档里，全靠人记与评审提醒。解释性注释的形态高度固定：变更叙述、会话与栈范围、评审视角、已死的草稿引用、控制流复述、规划残留、作者口吻、隐喻词。这类文字可以被词形识别，而靠人记的规则在会话规模上会失守。

词形判定天然有两个方向的错：漏过解释性注释，或误伤合法注释。两者的代价不对称——漏过的那处留在代码里无人发现，误伤的那处会被门禁当场报出、由人决定改写还是标记。规则因此取宽口径。

## Decision

`pnpm run check:comment-prose` 扫描 `src/` 的注释，按八类词形判定，命中即失败。规则表与扫描器在 `scripts/comment-prose.ts`，CLI 在 `scripts/verify-comment-prose.ts`，存量在 `comment-prose-baseline.json`。

注释由 TypeScript 编译器 API 抽取，不使用自写的词法状态机：取 AST 上各节点的前后注释 trivia，再剔除落在 JSX 文本节点里的部分（`<div>// 文本</div>` 里的 `//` 是文本，trivia 扫描会误认）。字符串、模板字面量、正则与 JSX 属性由解析器自行排除，不产生注释 trivia。遍历必须走 `getChildren` 而非 `forEachChild`：JSX 表达式里的注释挂在子 token 上，后者会整段跳过。

规则取宽口径：可能属于解释性的词形一律拦下，误伤由基线或就地标记消化。因此「之前」「不再」「迁移后」「本次」「暂时」「实际上」这类在日常技术写作里常见的词也在规则内。

豁免标记是 `prose-ok: <理由>`，作用于它所在的整段注释。理由必填：空理由不产生豁免，且标记本身报 `marker-without-reason`。这一条让豁免成为需要论证的动作，而不是绕过门禁的快捷键。

存量按「文件 + 规则 + 注释原文」三元组核销，不含行号：无关改动不让基线失效，改写过的注释则成为新命中。核销按次数进行，同一段注释被复制到别处会产生第二次命中，因此基线保留重复项而不去重。基线只允许调低。

门禁挂在 `pre-commit`（`--staged`，只查本次暂存的 TypeScript 文件）、`pre-push`（全量）与 `pretest` 上。

## Alternatives considered

**自写词法状态机抽取注释。** 初期实现走的这条路，实测漏判了 JSX 文本与模板字面量插值内的定界符，且需要自己维护字符串、正则、插值与 JSX 文本之间的状态转换。解析器已经把这些边界处理完毕，重新实现只是把它们再错一遍。

**用 oxlint 的 JS 插件承载规则。** oxlint 的 JS 插件面只支持 ESLint 规则形态，注释级判断要在 AST 上取注释并按段聚合，写起来比独立脚本更绕；而门禁需要报告里带上注释原文与豁免理由，独立脚本能直接给出。

**豁免标记用 `eslint-disable` 风格。** 与 oxlint 的抑制语法统一看起来整齐，但语义不同：这里抑制的是散文规则而不是代码规则，混用会让两套门禁的抑制无法分辨。

**理由可选。** 书写更省事，代价是豁免变成随手可加的空壳，规则随之失去约束力。

**按行号记存量。** 行号随无关改动漂移，基线会频繁失效，维护者只能用 `--update` 反复重建，最终把基线当成噪声。

**词形取窄以减少误伤。** 窄口径下 `此前`、`不再`、`本次` 这类高频解释性词形会整批漏过，门禁退化为只拦最显眼的一小撮写法。误伤是可当面处理的噪声，漏过是静默的缺口。

## Consequences

宽口径带来大量存量命中：初次建基线时有 364 处，其中 `change-narration` 最多。基线只允许调低，因此这些命中会长期留在文件里，直到有人逐条清理或在行上标记理由。

词形规则仍是启发式：它拦下的是「可能属于解释性」的写法，不是「必然是」。判定标准由豁免理由承担——写理由的人要说明这处为什么不是变更叙述或写作过程判断。

门禁只看 `src/`。`scripts/` 与 `test/` 的注释可能命中同一批词形，但那里的注释密度与变更频率低，纳入范围会让规则面对大量规则表自身的字符串字面量。

## Testing

`test/comment-prose.test.mjs` 覆盖注释抽取（字符串、正则、模板字面量、JSX 文本与属性四个方向的伪注释）、八类规则的正反例、宽口径的故意误伤与其标记豁免、空的豁免理由、按次数核销的基线语义。门禁自证：往 `src/shared/lru-map.ts` 注入一处会话范围注释后门禁变红，回退后恢复绿。
